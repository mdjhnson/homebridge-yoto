# Security policy

## Supported versions

Only the latest release gets security fixes. Update to it before reporting a problem.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through [GitHub's private vulnerability reporting](https://github.com/mdjhnson/homebridge-yoto/security/advisories/new) instead.

Include what you found, how to reproduce it, and which version you're running. You should hear back within a week. Once a fix is released, the advisory is published and credits you, unless you'd rather not be named.

Problems with Yoto's own service or apps should go to Yoto, not here.
